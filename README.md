## 새 차시 추가하는 방법
1. 새 폴더(예: `peace-efforts/`)를 만들고 수업 HTML을 `index.html`로 넣습니다.
2. 파일 맨 아래 `</body>` 바로 앞에 다른 수업의 `← 수업 목록` 링크 한 줄을 복사해 넣습니다.
3. 메인 `index.html`의 `<ol class="lessons">` 안에 `<li>` 카드 하나를 복사해 번호·제목·설명·주소를 바꿉니다.
4. 커밋하고 푸시하면 1~2분 뒤 사이트에 반영됩니다.

## 2차시(2차대전 배경) 서버 (구글 시트 + Apps Script)
- `ww2-background/`의 **학생 제출, 무솔리니·히틀러 챗봇, 교사 현황판**은 구글 시트 「역사① 2학기 1차시 - 2차대전 배경 제출」에 붙은 Apps Script 웹 앱 하나로 동작합니다.
- 서버 코드: `apps-script/ww2-background/Code.js` (수정 후 그 폴더에서 `clasp push` → `clasp redeploy <배포ID>`)
- 제미나이 API 키와 교사 비밀번호는 코드에 넣지 않고, 시트 상단 메뉴 **[📚 수업 설정]**에서 입력합니다(스크립트 속성에 저장).
