## 새 차시 추가하는 방법
1. 새 폴더(예: `peace-efforts/`)를 만들고 수업 HTML을 `index.html`로 넣습니다.
2. 파일 맨 아래 `</body>` 바로 앞에 다른 수업의 `← 수업 목록` 링크 한 줄을 복사해 넣습니다.
3. 메인 `index.html`의 `<ol class="lessons">` 안에 `<li>` 카드 하나를 복사해 번호·제목·설명·주소를 바꿉니다.
4. 커밋하고 푸시하면 1~2분 뒤 사이트에 반영됩니다.
